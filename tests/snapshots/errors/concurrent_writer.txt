ConcurrentWriterError: run 'run_shared' advanced behind this writer

What failed:
  The sqlite EventStore handle expected run 'run_shared' to have head '41' (41 event(s)), but the atomic append check found head '42' (42 event(s)). No event was appended by this writer.

Why:
  Another Runtime or operator changed the same run after this writer observed its head. ActiveGraph permits many readers and concurrent writers to different runs, but exactly one logical writer may extend a given run so event order and projection remain deterministic.

How to fix:
  Discard or make this Runtime read-only, close its store, and reload the run from the authoritative log. Coordinate the host so only one writer resumes it. Do not catch this error and merely mint another event id; that would interleave two schedulers into one run.
